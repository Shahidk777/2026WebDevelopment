Web Technologies

HTML

HTML is an acronym that stands for Hypertext Markup Language.
It tells the browser where to put headings paragraphs etc.
It uses labels called tags to identify stuff like bracket p which is for a paragraph.

CSS

CSS stands for Cascading Style Sheets.
Its a language that is used to style and design the layout of web pages.
Its used for aesthetics like changing the color across web pages or adding a design.

JavaScript

Javascript is also a language that makes the webpage interactive.
It gives live updates without constantly refreshing the page.
Javascript is what makes a webpage functional like amazon uses java to make it easier to buy.

ReactJS

ReactJS is a free java library that is used to build interactive interfaces.
Its used to build visual parts of a webpage.
It was created by Meta previously "facebook" and its used to make cool UI's for webpages.
